# v8 follow-up implementation decisions made before benchmark collection

2026-10-23 (Asia/Shanghai). No benchmark response exists at this checkpoint.

1. Existing server Granite/Phi files differ in both byte length and SHA-256 from the publishers' fixed GGUF files. Existing files remain untouched and excluded. Official pinned GGUF artifacts must pass whole-file hashes before probes or scientific collection. Both official quantization file-type codes are checked, rather than inferred from names.
2. Eight GPU slots per added model, each with a 4096-token context; batch concurrency is an execution setting, not extra statistical replication. Each request explicitly sets temperature, seed, top-p=1, top-k=0, min-p=0, repetition penalty=1 and prompt-cache=false. Generation cap 2048, confidence cap 32. All task instructions reside in the user message. No system message is sent to Phi; its native template does not render that role. Granite's native template uses the current date: replace only that expression with the fixed literal October 23, 2026, preserving all other text, and disable optional thinking.
3. Stage A retains the v7 700 question IDs, seven seats and parser v7.1. Only Granite/Phi are sampled; old four-model observations are retained. Per-model/task development concentration is selected from the original eight-value grid, ties smaller beta; locked before test generation. PERM/RANK controls remain descriptive. New-family results cannot retroactively change the original three-model primary test.
4. Stage B uses 100 new development questions per task for all six models, after prior-record audits. One global successor is ranked by equal-task/equal-model accuracy, fewer overrides, smaller beta, smaller margin cap, then larger confidence-difference threshold. The top-ranked rule must satisfy every v8 development criterion. If it fails, stop even if a lower-ranked rule would pass: do not rescue the study by switching criteria after seeing development outcomes. This conservative operational clarification is fixed before any new-question collection. Undefined retention fails the retention condition.
5. The DEV comparator in stage B is selected for each model/task from beta={0,1,2,4,8,16,32,64} using those same 100 development questions, with ties choosing smaller beta. It is then fixed for pilot/final samples. Development and pilot cannot enter formal validation. Pilot and final phases start only after their preceding gates pass and their necessary manifests are written.
6. Historical corpus exports containing every training question are source catalogs, not model evaluation records. Audit them separately, then exclude all source question IDs/text found in actual protocol/request/result records. Empty or malformed historical HTTP artifacts are logged; readable nonstandard traces also receive conservative text matching. No claim excludes unrecorded prior use, semantic duplicates or pretraining exposure.
7. Missing/invalid generation seats are not replaced. Any missing confidence for a valid seat invokes M. All original question denominators are retained. Only transport failures receive up to three attempts; authorization failures stop new scheduling. Infrastructure outages pause execution without changing questions, parameters or cached outputs. Resume only unsent logical requests or prescribed uncompleted retries. A 2 GiB local free-space reserve pauses new scheduling.
8. No financial cost estimation. Hosted calls remain local and keys are never transferred to the GPU. Responses, request IDs, full messages, returned model labels, usage and failure statuses are retained in append-only fingerprints.

9. PRE-BENCHMARK FORMAT AMENDMENT: Four handmade Granite/Phi probes revealed alternate explicit answer markers, before any benchmark request. Stage A primary remains v7.1; additionally parse only final-line `Answer: (X)`, `Final answer: (X)` or an explicit terminal `(X=value)` assignment. No extraction of unlabeled reasoning numbers or label-dependent choice. Stage B applies this bounded v8.2 compatibility parser uniformly to all six models. Additional confidence is collected for newly parseable existing probe outputs without resampling generations. Both initial failures and compatibility results remain archived. Stage A v8.2 readouts are a sensitivity, not the original-primary replication.
