# v7：置信排序、权重集中程度与票数优势的配对机制实验

状态：正式采集前冻结；人工构造的接口探针不属于基准实验。该文件与算法、分析代码、题目列表及来源哈希一起冻结。任何修改另建记录，不覆盖冻结方案。开源 Qwen2.5-14B-Instruct Q5_K_M 已通过探针，正式纳入全部700题设计；权重及服务程序哈希见 gpu_manifest.json。并发上限为 DeepSeek 4、Qwen API 4、GLM 2、开源 GPU 4，独立调度；商业 API 始终在本机调用。

## 核心候选主张（尚未验证）

**固定答案池和置信排序时，高度集中的置信权重可能把有用的排序信号转化为有害的多数票推翻；这一风险取决于票数优势。一个不读取正确答案的票差限制，能跨模型减少误改，保留大部分纠错。**

英文候选主张：*On fixed candidate pools, concentrating confidence weights can increase majority-overturning harm without changing confidence rankings; a predeclared vote-margin restriction can reduce this harm while retaining most recoveries across models.*

这是待检验的经验主张，不是已成立的新定理。“温度控制频率与置信的权衡”、排序聚合及纠错减误改的恒等式已有相关工作，不能声明为首次提出。本实验的潜在增量在于：完整固定候选池、严格保持排序的干预、保持分数直方图的打乱对照、预先固定票差规则、跨模型与跨任务共同检验。若效果不成立，应保留失败结果，不把别的事后观察改称原假设。

## 干预和对照

记有效候选答案为 a_i，自评分数 s_i∈[0,100]，c_i=s_i/100。

1. **M**：票数最多的答案；并列取最早出现者。
2. **W_beta**：权重 proportional exp(beta*c_i)，按答案累计；精确并列取最早出现者。beta∈{0,1,2,4,8,16,32,64}；beta=0 明确定义为 M。正 beta 保持候选排序及所有置信并列不变。
3. **G64**：当第一与第二大票数之差≥2 时返回 M；否则采用 W64。一致答案池视为有票数优势；规则不读取 gold，不在开发题或检验题上挑阈值。
4. **DEV**：每个模型×任务在 50 道开发题上选 W_beta，准确率并列选较小 beta，允许 beta=0。开发锁定文件提交后才生成检验题候选。这是有调参的参考基线，不是原始 CISC 最优复现。
5. **PERM4 / PERM64**：每题把置信分数在有效候选间均匀打乱 200 次；固定种子，每次保留同一分数直方图与权重集中程度，破坏分数与具体候选的对应。报告平均准确率，不将 200 次当成样本。只有一个答案类时无需模拟。
6. **RANK4 / RANK64**：把分数换为题内 midrank/(n-1)，再采用同一权重规则；并列保持并列。作为分数尺度敏感性分析，不能冒充新的独立实验。

只要任一有效候选缺少合法置信，该题所有评分依赖分支回退 M；空候选池统一弃权。所有分支共用有效候选，报告缺失率及完整案例敏感性。格式失败不重试；仅传输/408/429/5xx 最多三次，原始响应先保存。401/402/403 停止新调度。没有按表现替换问题、候选或服务端模型。

## 预先固定的统计检验

两项共同主要检验，均先在三家商业 API 上按模型等权、两任务等权计算，题目为簇：

- **H1**：W64 的误改风险高于 W4。误改 = M 正确而当前方法错误（包括弃权）。效应为全部题目上的误改比例差；不是仅在事后改判子集里比较。
- **H2**：G64 准确率高于 W64；同时报告 G64 保留的 W64 纠错比例。预定实际价值门槛为至少保留 75% 的纠错（点估计，并报告区间），若 W64 没有纠错，保留率不可定义，不能宣称已满足。

对每个题目先平均三个商业模型的配对差。计算等权两任务均值、任务内样本方差组成的标准误及 Welch–Satterthwaite t 检验；双侧 p 值经 Holm 在这两项中校正，效应方向必须与假设一致。区间使用 10000 次按任务分层、按题目成簇的配对 bootstrap；每次保留全部模型及全部策略。两项主要 p 值依赖题目间独立/可交换和大样本近似，API 漂移仍是限制。单模型×任务给精确 McNemar 及配对区间；这些属于描述性分解，不新增主要显著性声明。

完整支持需要：H1、H2 都方向正确且 Holm p<.05；G64 纠错保留率达到预定点估计门槛；至少 4/6 商业模型×任务单元的 H2 严格为正，且覆盖每家模型和两类任务。开源模型是预先增加的外部复核；若开源方向相反，必须收缩“跨模型”表述。若 H2 只有不足 20 道独立题目的正确性变化，则将机制证据评为稀疏/不足，不以不显著宣称等效。

其他必须报告：全部 beta 的纠错/误改/准确率/改判/越出票数最高类比例、候选正确率、题内正确-错误分数判别 AUC（题级平均，分数并列记 0.5）、恒定分数比例、有效权重样本数、不同票差层的结果、真实对应相对打乱对应的增量、DEV 参考基线、全部模型单元、开源加入前后汇总。不得只展示最好 beta。

## 样本量敏感性与停止规则

600 道独立检验题；三个商业模型不是1800道独立题。保守按配对二元差且差异概率 d=.05/.10/.20，双侧 alpha=.025（两主要检验的保守门槛）、80% power 的正态近似可检测差约为 2.82/3.98/5.63 个百分点；模型平均可能降低方差但不预先保证。不是为1个百分点等效或部署安全担保而设计。100道开发题不计入检验样本量。

固定样本数，不按中途显著性停止、不边看检验正确率边增加题量。传输进度、格式/长度错误及身份日志可以监测；检验效果在完整采集后一次性分析。商业 API 最多29400个逻辑请求，开源完整加入时增加9800个；重试与能力探针另记。只报告请求、token、耗时，**不估算费用**。

## 可证明的诊断与创新边界

若唯一多数类计数为 n1、次大计数 n2，正权重满足 w_max/w_min < n1/n2，则加权结果必为多数类：多数类总重≥n1*w_min，而任意竞争类≤n2*w_max，严格不等式排除并列。softmax 下充分条件为 beta*(max c-min c)<log(n1/n2)。零分数跨度或仅一个答案类直接保持多数。该条件只证明“不会改判”，不证明多数答案正确；不满足时也不必改判。它是基础充分条件，用于连接集中程度和票数优势，**不声称是一项此前未知的理论突破**。

主要文献边界：CISC (2025, https://aclanthology.org/2025.findings-acl.1030/) 已研究温度与题内置信；Ranked Voting (2025, https://aclanthology.org/2025.findings-acl.744/) 与 RISC (2026, https://arxiv.org/abs/2606.05054) 涉及排序聚合；VecCISC (2026, https://arxiv.org/abs/2605.08070) 涉及候选过滤；When Debate Helps (2026, https://arxiv.org/abs/2610.04686) 涉及固定候选与纠错/损害分解。相邻文献检索不等于穷尽检索；论文最终新颖性仍须谨慎定位。

冻结前新增核对：*Reasoning Concentrates Errors, and Self-Consistency Never Notices* (2026-09-25, https://arxiv.org/abs/2609.32035) 已有多模型置信加权未胜多数票、错误答案集中、模式切换和信号迁移的研究。因此“加权未胜多数票”及“判别能力不等于决策收益”均不能作为本研究独有发现。本研究仅尝试识别下游的权重集中干预×票差交互；并不比较思考模式，不声称解释上游错误集中原因，也不将本研究的简单双阈值控制包装成新的通用最优算法。
